# Proposed app licensing

Prepared at the owner's request on 2026-11-16. **Draft only; not yet adopted.**

- [Boundaries and provenance](SCOPE.md): MIT foundation, published iPhone baseline,
  candidate extensions, mixed-file treatment and exclusions.
- [Noncommercial license draft](drafts/APP-NONCOMMERCIAL.md): noncommercial use,
  modification and redistribution; commercial use only by separate express written
  permission from the proposed licensor, Maximilian Arnold.
- [Machine-readable snapshot](scope-manifest.json): exact baseline/current hashes.

This proposal is source-available, not OSI open source. The original
[MIT license](../LICENSE) is preserved. The draft does not retroactively restrict
anyone's existing MIT rights. It is a working legal draft, not a legal opinion;
review ownership, enforceability and the actual release boundary before adoption.

Reference review:
- https://opensource.org/osd — open source permits commercial use.
- https://choosealicense.com/licenses/mit/ — preserved MIT permissions/notices.
- https://polyformproject.org/licenses/noncommercial/1.0.0 — standardized alternative
  considered. Its organization exceptions do not exactly match the owner's strict
  commercial-permission requirement, so this draft is not labeled PolyForm.
